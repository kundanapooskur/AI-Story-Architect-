Key Features & Components

Four advanced AI components working together to create consistent, engaging narratives

🔍

Component 1: RAG System

Retrieval-Augmented Generation with LangChain & Pinecone

  • LangChain 0.1.0 framework
  • Pinecone vector database (1536-dim)
  • 5 chunking strategies (sentence, paragraph, semantic, fixed, auto)
  • Hybrid search with re-ranking (70% semantic + 30% keyword)
  • 1800+ vectors: 4 classic novels + fantasy novel
  • Citation grounding with source attribution
  • Top-k retrieval (k=3, 5, 8)
  • 250ms average search latency
🤖

Component 2: Prompt Engineering

Multi-agent system with Pydantic validation

  • Character-specific AI agents
  • Specialized system prompts per character
  • Narrative director for plot coordination
  • Dynamic context window management
  • Pydantic models for structured outputs
  • RAG memory injection (top-5 relevant)
  • Consistency validation (85%+ accuracy)
  • Error handling with retry logic (95% recovery)
🎨

Component 3: Multimodal AI

Text, image, and audio generation

  • DALL-E 3 scene visualization (1024x1024)
  • Scene-to-image prompt optimization
  • Character portrait generation
  • Style consistency (fantasy, anime, realistic, etc.)
  • Google Text-to-Speech narration (free)
  • Cross-modal generation pipeline
  • 98% image success rate
  • 30-60s image generation time
🔬

Component 4: Synthetic Data

Training dataset generation and export

  • Alternative story branch generation (3-5 variations)
  • Dialogue augmentation with diverse phrasings
  • Plot twist generation
  • Diversity metrics (TTR, vocabulary, sentence diversity)
  • Export to JSON, CSV, JSONL (training-ready)
  • Dataset statistics tracking
  • 0.68 average lexical diversity
